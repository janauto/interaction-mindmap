# data.json 结构

`scripts/build_page.py` 读取这份文件，填进 `assets/template.html`。三块：`meta`（页面文案与行为）、`assets`（素材表）、`tree`（脑图）。

```json
{
  "meta": {
    "title": "示例设备交互脑图",              // <title>，两到四个词的名字，不加解释
    "heading": "示例设备交互脑图",            // 页面大标题，缺省同 title
    "eyebrow": "团队名 · 2026-11-09 整理",
    "lede": "按目前构建的版本整理：<b>…</b>",  // 允许少量 HTML
    "base": "assets/",                        // 素材目录，相对输出 HTML
    "legend": [["ok", "实机", "设备上验证过"], ["pv", "预览", "只在电脑预览里跑过"]],
    "kinds": {"ok": "设备实拍截屏", "ph": "手机实机截图"},  // 素材来源类型的显示名，可扩展
    "openDepth": 2,                           // 首屏展开到第几层（0 根，1 一级分支）
    "tourMs": 3600,                           // 自动导览每张停留毫秒
    "autoDetail": true,                       // 切到带细节框的图时，0.7 s 后自动放大到细节
    "maxZoom": 6,
    "searchPlaceholder": "搜索：如 SET、抽屉",
    "extraHtml": "<h2>两代交互对照</h2><div class=\"tbl-wrap\"><table>…</table></div>",
    "footer": "依据：…（逐条写素材来源与日期）"
  },
  "assets": {
    "stage": {"f": "stage.webp", "k": "ok", "c": "舞台 · 数码外观（串口截屏 2026-10-23）"},
    "flow":  {"f": "flow.gif",  "k": "pv", "c": "上推打开抽屉（预览动图）", "wide": false},
    "card":  {"f": "card.webp", "k": "cs", "c": "某竞品屏幕特写（某评测网站，2026-11）",
              "u": "https://…", "focus": [0.31, 0.22, 0.38, 0.30]}
  },
  "tree": {
    "t": "示例设备", "d": "功能交互全景", "i": "root",
    "c": [
      {"t": "设备端", "short": "设备端", "color": 1, "i": "overview", "s": ["ok"],
       "c": [{"t": "长按 600 ms → 说话", "d": "正在听 → 识别 → 气泡回复", "i": "listen", "z": [0, 0.7, 1, 0.3]}]}
    ]
  }
}
```

## 字段

**素材 `assets[key]`**

| 字段 | 必填 | 含义 |
|---|---|---|
| `f` | 是 | 文件名，位于 `meta.base` 下 |
| `k` | 是 | 来源类型码，显示为图下标签。内置 `ok pv sm br cs td`，可在 `meta.kinds` 里改名或新增（如 `ph` 手机实机、`rd` 渲染、`dg` 文档配图、`dm` 演示动图） |
| `c` | 是 | 图说：画面内容 + 来源 + 日期。第三方图片必须写出处 |
| `u` | 否 | 来源链接，显示为「来源」 |
| `wide` | 否 | 横图，缩略图用宽框 |
| `focus` | 否 | 细节框 `[x, y, w, h]`，取值 0–1、相对原图。有它时大图出现「细节」按钮，并可自动放大 |

**节点 `tree` 及其 `c` 子节点**

| 字段 | 必填 | 含义 |
|---|---|---|
| `t` | 是 | 标题，可含 `<kbd>M</kbd>` 这类按键标记 |
| `i` | 是 | 素材 key。每个节点都要有图 |
| `d` | 否 | 一行说明 |
| `s` | 否 | 状态徽标数组，取 `ok pv cs br td sm`，文字由 `meta.legend` 定义 |
| `c` | 否 | 子节点数组 |
| `color` | 一级分支 | 1–6，对应模板里的六种分支色（浅深色各一套） |
| `short` | 否 | 一级分支在「看哪一支」筛选条上的短名 |
| `z` | 否 | 节点自己的细节框，优先于素材的 `focus`。同一张图给不同节点放大不同区域时用它 |

## 细节框怎么量

1. 用 `scripts/contact_sheet.py out.png --cols 2 --cell 700x900 原图` 放大看原图。
2. 估出关注区域的像素框 `(x0, y0, x1, y1)`，换算成 `[x0/W, y0/H, (x1-x0)/W, (y1-y0)/H]`，保留两位小数。
3. 生成页面后在大图里按 `D` 或点「细节」，看放大是否正好落在目标上，偏了就微调。
