# 页面行为与发布

## 页面已经做好的交互（模板自带，不用改）

| 区域 | 行为 |
|---|---|
| 脑图 | 从左向右展开；点节点展开 / 收起，子节点依次滑入、连线生长；悬停节点上浮、缩略图放大 |
| 工具条 | 「看哪一支」只看某个一级分支；全部展开 / 只看概要；搜索高亮并自动展开命中路径；自动导览 |
| 缩略图角标 | `GIF` 表示动图，`⌕` 表示带细节框 |
| 详情面板 | 桌面在右侧滑出、手机从底部升起；面包屑、来源标签、图说、标题、说明 |
| 场景切换 | ← / → 或「上一个 / 下一个」按全树顺序切；面板里的场景条可一键跳到同一父节点下的其他场景；手机上左右滑大图 |
| 细节放大 | 滚轮 / 双指缩放，双击在点击处放大到 2.5×，放大后拖动平移；`+` `-` `0` 键；有细节框时「细节」按钮或 `D` 键放大到框内，`autoDetail` 开启时切图 0.7 s 后自动放大 |
| 导览 | 每张停留 `tourMs`，底部进度条，脑图同步定位到当前节点并脉冲高亮 |
| 无障碍 | 节点、缩略图可键盘操作；Esc 关闭；系统开启「减少动态效果」时动画全部关闭 |
| 主题 | 浅色 / 深色两套色板，跟随系统，也响应 `data-theme` |

## 生成与自检

```bash
python3 scripts/build_page.py data.json -o site/index.html --strict
python3 scripts/check_page.py site/index.html --shots /tmp/check
```

`build_page.py` 报告缺图、引用错误、缺图说、细节框格式错误；`check_page.py` 在 1440 px 浅色和 390 px 深色下检查无图节点、坏图、脚本错误、横向溢出，并截两张图。看一眼截图再发布，有问题修一轮即可，不要反复循环。

## 发布为 Artifact（Claude 桌面 / claude.ai 环境）

- 第一次发布前按 Artifact 工具要求加载页面设计指引（quickstart，intent 选 other）。模板已满足页面约定：`<title>`、侧边安全区、浅深色 token、`body` 背景、手机宽度无横向滚动。
- 素材用 `files` 一起发布：`root` 设为 HTML 所在目录，`files` 列出 `assets/xxx` 每个文件。发布路径用英文目录名，中文目录名可能出问题。
- 同一份页面再次发布用同一个文件路径，保持同一个链接；不同交付物（比如自家产品和竞品）各自一个链接。
- Artifact 默认私有，告诉用户需要从页面的 Share 菜单分享给别人。
